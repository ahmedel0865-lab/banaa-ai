أسئلة شائعةFAQ

قبل ما تبدأ، إجابات أسرع الأسئلةQuick answers before you start

هل بيانات مشاريعنا هتكون في أمان؟Is our project data safe?

أيوه. بنحط سياسة استخدام واضحة، ونقدر نشغّل الحلول جوه شبكة الشركة من غير ما الملفات تطلع برّه.Yes. We set a clear usage policy and can run solutions inside your network so files never leave it.

لازم فريقنا يعرف برمجة؟Does our team need to code?

لأ. الأدوات بتتسلّم جاهزة، والتدريب بيبدأ من الصفر، وكتير من الشغل بيتعمل بالكلام مع المساعد.No. Tools are delivered ready to use, training starts from zero, and much of the work is done by chatting with the assistant.

بتشتغلوا على أنهي برامج؟Which software do you work with?

Revit و AutoCAD و Dynamo و Excel و Primavera و Power BI، وأي نظام عنده API نقدر نربطه بـ MCP.Revit, AutoCAD, Dynamo, Excel, Primavera and Power BI, plus any system with an API we can connect through MCP.

إمتى هنشوف نتيجة؟When will we see results?

في المشروع التجريبي، خلال 3 لـ 6 أسابيع، وبرقم متقاس قبل وبعد.In the pilot, within 3 to 6 weeks, with a measured before-and-after number.

التدريب أونلاين ولا حضوري؟Is training online or in person?

الاتنين. كورسات أونلاين للأفراد، وبرامج في مقر الشركة للفرق.Both. Online courses for individuals and on-site programs for teams.
